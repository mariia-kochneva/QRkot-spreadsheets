## 📝 Описание

QRKot - это веб-приложение для благотворительного фонда поддержки котиков. Фонд собирает пожертвования на различные нужды кошачьей популяции: корм, медицинское обслуживание, организацию приютов и другую помощь.

### Основные возможности:
- 📋 Создание и управление целевыми проектами для сбора средств
- 💰 Приём пожертвований от зарегистрированных пользователей
- 🔄 Автоматическое распределение пожертвований по открытым проектам
- 👤 Регистрация и аутентификация пользователей
- 🔐 Разграничение прав доступа (аноним, пользователь, суперпользователь)
- 📊 Просмотр статистики по проектам и пожертвованиям

## 🚀 Технологии

- **FastAPI** - современный веб-фреймворк
- **SQLAlchemy 2.0** - асинхронная ORM
- **SQLite/aiosqlite** - база данных
- **Pydantic V2** - валидация данных
- **FastAPI Users** - аутентификация и управление пользователями
- **JWT** - JSON Web Tokens для авторизации
- **Swagger UI** - автоматическая документация API

## 📦 Установка

### 1. Клонируйте репозиторий:
```bash
git clone <url-репозитория>
cd cat-charity-2
```

### 2. Создайте и активируйте виртуальное окружение:
```bash
# Linux/Mac
python -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```

### 3. Установите зависимости:
```bash
pip install -r requirements.txt
```

### 4. Примените миграции:
```bash
alembic upgrade head
```

### 5. Запустите сервер:
```bash
uvicorn app.main:app --reload
```

Приложение будет доступно по адресу: **http://localhost:8000**

## 📚 Документация API

После запуска сервера документация доступна по адресам:

- **Swagger UI:** http://localhost:8000/docs
- **ReDoc:** http://localhost:8000/redoc

## 👤 Права доступа

### Анонимный пользователь
- Просмотр списка проектов
- Регистрация

### Зарегистрированный пользователь
- Просмотр списка проектов
- Создание пожертвований
- Просмотр своих пожертвований (без информации об инвестировании)

### Суперпользователь
- Все права зарегистрированного пользователя
- Создание, редактирование и удаление проектов
- Просмотр всех пожертвований с полной информацией

## 🔄 Логика инвестирования

### При создании проекта:
- Все свободные (не распределённые) пожертвования автоматически инвестируются в новый проект
- Средства распределяются в порядке очерёдности пожертвований (сначала старые)

### При создании пожертвования:
- Средства автоматически распределяются по открытым проектам
- Приоритет у проектов, созданных раньше
- Если сумма пожертвования больше, чем нужно текущему проекту - остаток переходит в следующий проект

## 📋 API Эндпоинты

### Аутентификация (`/auth`)
| Метод | URL | Описание | Доступ |
|-------|-----|----------|--------|
| POST | `/auth/register` | Регистрация | Все |
| POST | `/auth/jwt/login` | Вход | Все |
| POST | `/auth/jwt/logout` | Выход | Авторизованные |

### Проекты (`/charity_project`)
| Метод | URL | Описание | Доступ |
|-------|-----|----------|--------|
| GET | `/charity_project/` | Список проектов | Все |
| POST | `/charity_project/` | Создать проект | Суперпользователь |
| PATCH | `/charity_project/{id}` | Редактировать | Суперпользователь |
| DELETE | `/charity_project/{id}` | Удалить | Суперпользователь |

### Пожертвования (`/donation`)
| Метод | URL | Описание | Доступ |
|-------|-----|----------|--------|
| GET | `/donation/` | Все пожертвования | Суперпользователь |
| POST | `/donation/` | Создать пожертвование | Пользователи |
| GET | `/donation/my` | Мои пожертвования | Пользователи |

### Пользователи (`/users`)
| Метод | URL | Описание | Доступ |
|-------|-----|----------|--------|
| GET | `/users/me` | Мой профиль | Авторизованные |
| PATCH | `/users/me` | Обновить профиль | Авторизованные |
| GET | `/users/{id}` | Пользователь по ID | Суперпользователь |
